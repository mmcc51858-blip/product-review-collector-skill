# 淘宝 / 天猫、京东 CDP 商品评价采集

## 当前能力与准备

包内 `scripts/cdp/` 提供本机浏览器附着、评论抽取、分页 / 滚动、按条数停止、截图、断点去重与 CSV / JSONL 和带图 Excel。天猫 PC 与京东 PC 已各完成一个真实商品 50 条测试。模板带有本次实测选择器，使用时仍需核验商品、筛选与页面结构；淘宝 C2C 和京东移动页未通过本轮验收。

电脑需要 Python 3.10+、Chrome 或 Edge，以及 `python -m pip install -r scripts/cdp/requirements.txt`。用同一个 Python 解释器执行安装和采集。只附着已有浏览器时不需要下载 Playwright 浏览器。手机和 USB 不是 CDP 路径的依赖，手机端也不需要打开 Codex。

优先使用环境已有且适合任务的浏览器工具；用户选择 CDP 时可用本包脚本。若环境明确规定了专用浏览器入口，遵守该入口，不用脚本绕过。CDP 端点仅接受无凭据的本机回环地址，不开放到公网。

## 登录与选择商品

复用用户授权的 CDP 会话。没有会话时，可用 `scripts/cdp/start-browser.ps1` 创建专用浏览器用户目录；只有用户需要看窗口并登录时使用 `-Interactive`：

```text
powershell -File scripts/cdp/start-browser.ps1 -Browser edge -Port 9222 -Interactive
python scripts/cdp/collect.py probe --cdp http://127.0.0.1:9222
```

登录由用户在浏览器完成。Cookie 留在专用目录，不读取、导出或打包登录态。不要改用日常默认浏览器用户目录，也不要关闭其他浏览器。采集脚本结束只断开连接，不关闭用户窗口。

`probe` 输出标题和去查询参数的 URL。淘宝商品 ID 可能位于查询参数，因此不得只凭去参数 URL 确认商品；结合用户原链接、浏览器实际地址及页面标题核对，将已核验商品 ID 填入 `target_id`。多个标签页命中时收紧 `page_url_contains`，禁止选择第一个标签页。网页引导到 App、登录失效、验证码或限流时保存状态并停下。

## 平台适配

复制对应模板到本次任务目录，不修改包内原始模板：

- 淘宝 / 天猫：`assets/cdp/taobao.adapter.json`。确认实际平台是淘宝还是天猫，选择对应商品的全部评价区域；记录实际排序、全部或指定款式。主评、追评、商家回复分清归属，不把商品详情预览或推荐商品当评价。
- 京东：`assets/cdp/jd.adapter.json`。核对实际商品 ID 与所选规格；记录页面是否聚合其他规格，按当前实际筛选采集。商品介绍、问答、评论标签、晒单计数都不算独立评论。

两平台均按现场 DOM 填写 `card_selector`、`fields.text.selector` 和需要的日期 / 规格 / 星级 / 作者选择器。不存在的字段删去或明确缺失，不猜页面类名，不把示意选择器标成平台可用适配。

天猫的购买信息可能把日期与规格写在同一个节点。字段配置可选 `pattern` 和 `group`（默认第 1 组），按已观察的文字拆分；保留 `purchase_raw` 原文。例如日期 `"pattern":"(\\d{4}年\\d{1,2}月\\d{1,2}日)"`，规格 `"pattern":"已购[:：]\\s*(.*)"`。未匹配时留空并检查，不补写日期或规格。

京东可能默认聚合同系列的其他药品。需要当前链接商品时，先在评价面板勾选现场的“当前商品”，确认激活状态及几条规格确实属于目标商品，再采集。不要把“当前商品”仅作为常驻标签存在就当作已勾选。页面“最新”可能是可点击的排序入口，不能因为存在这两个字就宣称已按最新排序。

先用浏览器工具观察、展开全文并核验 3–5 条：正文、商品 ID、评论 ID、日期、规格、星级、截图与图片是否对应。iframe 必须准确选择，使用实际观察的 `frame_url_contains`；评论浮层的选择器须限定在该评论区域。若每页都有折叠正文，先按实际页面扩展“展开”操作，再采集，不能只展开第一页。

`id_attribute` 仅填卡片实际提供的评价 ID 属性。优先按平台+商品+评价 ID 去重；缺少 ID 时按正文+日期+匿名作者+规格保守去重，说明同文评价可能合并。昵称只保存匿名键，避免收集买家主页与联系方式。

核验后将任务配置设为 `verified=true`，才允许运行。配置不能与其他商品或排序混用。

## 数量、分页和停止

```text
python scripts/cdp/collect.py collect --cdp http://127.0.0.1:9222 --config <已核验配置> --out <该商品任务目录>
python scripts/cdp/collect.py collect --cdp http://127.0.0.1:9222 --config <已核验配置> --out <该商品任务目录> --limit 50
```

第一条为全部模式，无隐含条数、页数或时长预算。第二条按 50 条唯一评论停止。可在初次适配时显式用 `--max-pages 1` 试采；结果属于试采部分，非全量。只有本次任务确有预算才添加 `--max-pages` / `--max-minutes`。

`pagination.mode` 可为 `next`、`scroll`、`none`：下一页按钮或滚动容器必须来自现场观察。`none` 仅取当前页。无限滚动页重复加载的卡片由 ID / 指纹去重。`wait_ms` 留正常加载时间，不承诺规避平台限制。

虚拟列表会在滚动后替换同一位置的卡片。配置 `capture_viewport` 为实际评论滚动容器，仅取完整位于视口内的卡片；`viewport_top_inset` 避开实际粘性顶栏；`pagination.step_px` 控制保留重叠的小步滚动。本次京东测试值为 54 像素顶栏、230 像素滚动步长，需依设备重新观察。`media_selector` 可限定买家图片，截图前等待正常加载。过高的卡片可能无法完整进入视口，需另行跨屏取证，不得跳过后声称全量完成。

采集器对截图前后的正文、日期、规格和作者键做一致性核对；`CARD_CHANGED_*` 表示卡片发生变化，停止保存此条并检查，不能把已错配的截图交付。检查源文字与截图头部、中段、末尾，单凭截图文件存在不足以证明对应关系正确。

`end_selectors` 只填已核验的终止提示或状态元素的选择器，不能填常驻页脚或猜测的“无更多”类名。未观察到时留空。

| 结束原因 | 解释 |
| --- | --- |
| `LIMIT_REACHED` | 已达到用户指定的唯一条数 |
| `END_MARKER` | 已观察到配置中核验过的终止元素；结合商品 / 筛选核对范围 |
| `NEXT_DISABLED` | 下一页禁用；仍须结合页面总数和当前页判断可访问范围 |
| `MAX_PAGES` / `TIME_LIMIT` | 达到显式运行预算，部分完成 |
| `NO_NEW_REVIEWS` / `CONTENT_UNCHANGED` | 无新增或未更新，暂停检查，不能报全量完成 |
| `SINGLE_PAGE` / `NO_NEXT_CONTROL` / `NO_REVIEW_TEXT` | 当前页采样、缺少入口或解析异常，不能报全量完成 |
| `PAGE_CHANGED` / `CARD_CHANGED_*` / `MEDIA_NOT_READY` / `WAIT_HUMAN` / `HTTP_*` / `ERROR_*` / `INTERRUPTED` | 页面跳转、卡片变化或其他异常，保存已有结果，处理原因后再继续 |

相同目录续跑会校验平台、商品、筛选及配置哈希，优先恢复去重记录。它不会把浏览器自动恢复到旧页码；先核对当前商品、排序及位置，再续跑。多商品逐个配置、逐个保存，不共用断点目录。任意页面变更、无效控件、验证或登录提示先保存并停止，不反复点击。

## 响应取证与输出

正常页面操作后可被动留存评论响应。仅在观察到实际评论 host/path 后配置 `response_allowlist`；脚本不调用、猜测或重放接口。响应文件经过脱敏，SHA256 对应保存后的文件，不是原始网络字节。网络留存不会自动生成评论，不能据此宣称已经完成响应字段映射。

- `reviews.jsonl`：平台、商品 ID、筛选、评价 ID、原文、原始星级 / 日期 / 规格、匿名作者键、截图路径、采集时间；URL 去查询参数，商品 ID 单独保留。
- `reviews.csv`：UTF-8 BOM；为防止打开表格时执行公式，公式前缀文本会加单引号。原文以 JSONL 为准。
- `pages/`：各评论卡片的 PNG 与每批抽取记录、截图哈希。先核对图片加载与卡片归属，长评论及跨屏媒体按需要补拍。
- `responses/`：可选的范围内脱敏响应，不保存请求头、Cookie、token 或整个网络档案。
- `state.json`：任务身份、唯一数、已保存批数、数量模式、停止原因与断点。

图片默认是评论卡片截图，非原图。只有正常页面能力能取得原图且归属已核验时才另存原图；本采集脚本未实现原图下载。有视频时截图只代表可见画面。

## 表格与图片交付

默认交付内嵌截图的 Excel，CSV / JSONL 作为备份。**不能停在 CSV 阶段**。按 [统一 Excel 交付](excel-delivery.md) 使用统一导出器和固定列；没有 Codex 专用表格运行库的电脑使用包内 Python 便携方案。旧 `scripts/cdp/export_reviews.mjs` 三个位置参数入口仍兼容，内部转给统一导出器。

原始日期保留文字，京东未显示年份的月日不擅自补年；仅有星级图示而无文字时不按 CSS 类名推断分数。页面统一显示“匿名买家”的记录仍标为平台匿名，不将共享的匿名键当作同一个人。Excel 用压缩预览，原始截图另行打包。字段以外的评论分析为可选，用户没要求时不加。

交付前核对唯一数、去重依据、字段映射、截图存在及归属；抽查开头 / 中段 / 末尾，渲染检查换行、行高和图片锚点。归档时不打包浏览器用户目录、登录信息、本机绝对路径或无关标签页。最后报告实际条数、筛选、图片类型、终止原因与缺口，不能把当前样本当平台全量。

## 验证范围

本地浏览器测试覆盖 12 项：原有 9 项，以及日期 / 规格拆分、卡片截图期间回收时拒绝保存、可见视口小步采集。安卓原有 9 项回归测试保留。

真实页面验证：天猫 PC 与京东 PC 各一个商品、各 50 条，均保留正文、日期原文、规格和对应评论截图；京东勾选“当前商品”。没有平台评价 ID，按指纹保守去重。测试目标和采集材料未公开。此次仅验证指定条数，未验证全量采尽。虚拟列表首轮出现的截图错配已通过重新采集及截图前后字段核对修正。

## 官方依据

[Playwright CDP 附着文档](https://playwright.dev/python/docs/api/class-browsertype#browser-type-connect-over-cdp) 说明该连接适用于 Chromium 浏览器，部分功能弱于 Playwright 原生连接。[Chrome 调试端口说明](https://developer.chrome.com/blog/remote-debugging-port) 说明新版 Chrome 对非默认用户目录的要求。这里不提供淘宝或京东的非公开评论接口或未经验证的页面选择器。
