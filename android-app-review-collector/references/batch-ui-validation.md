# 安卓真机验证范围

抖音商城独立 App 已完成两个商品各 50 条的指定数量测试。每条保留正文、日期原文、购买规格和截图，逐个商品独立保存断点并导出带图 Excel。此公开版不包含原商品链接、分享口令、原始评价或截图。

测试前由操作者完成 USB 调试授权、解锁、登录并打开商城。后续通过“最近任务暂置商城 → 写入用户提供的分享文案 → 恢复已有商城任务 → 观察商品弹窗 → 详情 → 全部评价”进入目标商品，再滚动采集。手机端无需运行 Codex。

采用正文与规格的保守去重，缺少平台评价 ID 时可能合并同文评价。本次验证指定数量，不能证明全量采尽。首部、中段和末尾均检查原始页面、字段和截图归属，并验证表格图片锚点及 XLSX 完整性。

已处理的问题包括：搜索口令混入同名推荐、输入法改写口令、最近任务动画导致定位不稳、筛选标签混入规格，以及末条图片跨屏。方法与现场参数核验见 [界面导航](batch-ui-test.md)。

此流程仍由代理逐屏判断，不是任意链接的一键无人值守批处理器。App 版本、设备尺寸、包名、列表资源 ID、控件和商品弹窗均需重新观察；登录、验证、锁屏或商品不一致时停止并保留断点。
